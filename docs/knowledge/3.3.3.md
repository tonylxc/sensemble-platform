### 1. 理论核心
**电涡流传感器**：基于电磁感应原理。当线圈通以高频交变电流 $I_1$ 时，在线圈周围空间产生交变主磁场。当金属导体置于该磁场中时，导体内表面会产生闭环的感应电流，称为**电涡流（Eddy Current）**。

电涡流会反向产生逆向交变磁场，削弱原主磁场，从而导致原励磁线圈的等效电感量 $L$、等效阻抗 $Z$ 发生明显变动。该变动与金属导体的距离 $x$、材料电阻率 $\rho$、磁导率 $\mu$ 具有紧密函数关系。

**趋肤效应（Skin Effect）**：
高频交变磁场无法完全穿透金属导体内部，电涡流主要集中在金属导体的表面层，其电涡流密度自内表面向深处按指数规律衰减。电涡流透入的**标准趋肤深度（$\delta$）**严格遵循以下电磁物理方程：

$$\delta = \sqrt{\frac{\rho}{\pi f \mu}} = \sqrt{\frac{1}{\pi f \mu \sigma}}$$

式中，$f$ 为线圈励磁交流波频率，$\sigma$ 为导体的电导率。励磁频率 $f$ 越高，趋肤深度 $\delta$ 越薄。因此高频电涡流传感器具有极高极其灵敏的**表面非接触式距离形态响应**，非常适合高速轴承跳动及振动测试（测试上限常达数十千赫兹）。

### 2. 现代科技进展：航空发动机叶片尖端间隙（BTT）无线监测
在2026年主流的高端航空航天测试中，电涡流技术被广泛应用于旋转高达数万转的叶片尖端运行间隙（Blade Tip Timing, BTT）在线测定。传感器线圈采用耐 $1000^\circ\text{C}$ 以上高温的陶瓷复合骨架和稀土合金导线绕制。配合兆赫兹（$\text{MHz}$）级别的超高频励磁解调电路，能够实时捕捉超音速叶片边缘微米级的高频形变，直接在边缘端实现旋转数字孪生。
