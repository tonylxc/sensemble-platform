### 1. 理论核心
掌握消除和减小系统误差的技术措施是测试工程师的核心素养。工程中沉淀出了三大极其经典的削弱法：

1. **替代法（Substitution Method）**：在测量过程中保持仪器的工作状态前后不变，用等值且已知高精确度的标准量具去替换被测量。
   * *优势*：消除了因测量桥路、放大器非线性及不准引发的恒值系统误差（测量误差完全取决于替代标准量具的精度）。
2. **零位法（Zero-balance Method）**：在测量中调整已知标准量使检零仪表指零，系统处于平衡状态（如直流电位差计）。
   * *优势*：由于零位状态下流经仪表的电流 $I_p = 0$，**系统完全不向被测电路吸取物理能量**，彻底消除了因仪表阻抗有限引发的方法误差。
3. **微差法（Differential Method）**：将被测量 $x$ 与高稳定的标准量 $N$ 做对消，仅用高灵敏度直读仪表测量极小的微差 $\Delta x = x - N$：
   $$x = N + \Delta x$$

**微差法误差削弱的严格数学证明**：
微差法的总绝对误差传递方程为 $\Delta = \Delta N + \Delta\delta$。相对误差 $\gamma_x$ 表达为：

$$\gamma_x = \frac{\Delta}{x} \approx \frac{\Delta N}{N} + \frac{\Delta x}{N} \gamma_\delta$$

式中：
* $\frac{\Delta N}{N}$：标准量的相对误差（通常优于 $0.05\%$）。
* $\gamma_\delta = \frac{\Delta\delta}{\Delta x}$：直读仪表测量微差的示值相对误差（即使由于仪表精度低达 $\gamma_\delta = \pm 3.0\%$）。
* $\frac{\Delta x}{N}$：对消比值。由于微差极小（如 $0.5\text{V}$ 相比于基准 $25\text{V}$，比值为 $1/50$）。

代入计算：

$$\gamma_x \approx \pm 0.1\% + \frac{0.5}{25} \times (\pm 3.0\%) = \pm 0.1\% + \pm 0.06\% = \pm 0.16\%$$

*结论*：尽管微差测量表的精度仅为普通 $1.5$ 级，但通过微差法对消，**系统最终的总相对误差被强力压制到了极高精密的 $0.16\%$**。
