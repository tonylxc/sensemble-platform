### 1. 理论核心
**电阻应变效应**：导体或半导体材料在外界机械力作用下产生机械变形（拉伸或压缩）时，其物理阻值随之发生相应变化的物理现象。

设一根长度为 $l$、截面积为 $A$、电阻率为 $\rho$ 的金属丝，其初始电阻为 $R = \rho \frac{l}{A}$。当受到轴向拉力发生微小应变时，对该方程两边取全对数并求全微分，可推导出电阻相对变化量公式：

$$\frac{dR}{R} = \frac{dl}{l} - \frac{dA}{A} + \frac{d\rho}{\rho}$$

根据材料力学性质，设轴向线应变为 $\epsilon = \frac{dl}{l}$，材料的泊松比为 $\mu$，则截面积变化率为 $\frac{dA}{A} = -2\mu\epsilon$。带入上式可得电阻应变的基本通用方程：

$$\frac{dR}{R} = (1 + 2\mu)\epsilon + \frac{d\rho}{\rho}$$

定义**金属丝的应变灵敏系数 $K$** 为：

$$K = \frac{dR/R}{\epsilon} = (1 + 2\mu) + \frac{d\rho/\rho}{\epsilon}$$

对于常见的金属材料，电阻率变动极小（$\frac{d\rho}{\rho} \rightarrow 0$），其灵敏系数主要取决于**几何形变项 $(1+2\mu)$**，常数取值范围通常在 $1.8 \sim 2.2$ 之间。

### 2. 现代科技进展：柔性微纳电子皮肤与高灵敏碳纳米管（CNT）
在2026年智能机器人与医疗健康感测领域，传统金属应变片因量程极小（小于 $1\%$ 应变）无法应用于关节大范围运动。现代研发的**柔性电子皮肤（Flexible Electronic Skin）**将碳纳米管（CNT）或石墨烯浆料印刷在聚酰亚胺超薄柔性基底上。利用纳米颗粒间的隧道效应特性，其应变灵敏系数 $K$ 可突破至数十万级别，且支持高达 $300\%$ 的超大拉伸量程。
