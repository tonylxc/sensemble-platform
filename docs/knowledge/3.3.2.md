### 1. 理论核心
**差动变压器式传感器（简称 LVDT）**：基于电磁互感原理，将输入机械位移转换为二次侧两个互感线圈之间互感量 $M$ 差异的螺线管闭环器件。

在结构上，它包含一个初级励磁线圈和两个反向串联的反向串联的二次侧初级线圈。当中心活动铁芯处于绝对几何中心零位时，两二次侧线圈产生的互感电压大小相等、方向相反（$U_{21} = U_{22}$），理想总输出电压应为 $U_o = U_{21} - U_{22} = 0$。

**核心工程挑战：零点残余电压（Zero Residual Voltage）**：
在实际精密硬件制造中，当铁芯置于零位时，输出电压曲线并不归零，而是存在一个微小的残余交流电压包络（通常在几毫伏到几十毫伏区域）。
* **产生机理**：由于两桥路二次侧线圈的几何分布不完全对称、导线漆包线存在分布电容、以及铁芯材料内部存在高阶涡流损耗与磁滞损耗，导致 $U_{21}$ 与 $U_{22}$ 不仅幅值不完全相等，且存在**微小的相位差**，导致无法实现完全代数对消。

**经典硬件削弱措施**：
1. 在二次侧两端并联高精密的微调电阻和微调电容网络。
2. 采用相敏检波技术（Phase Sensitive Demodulation），由于残余正交分量在相位上与有用信号相差 $90^\circ$，通过正交同步开关解调可以在数学积算上将其滤除。

### 2. 现代科技进展：单芯片级数字 LVDT 信号调理器（如 AD2S1210 架构升级）
在2026年的数字化机床和重型工业控制中，复杂的离线残余电压微调电路已被完全集成在片上系统（SoC）中。调理芯片内部采用全数字化二阶闭环跟踪回路，通过片上内置的数字相敏检波算法，直接在纳秒级捕捉残余电压的正交项和高阶谐波分量，在线自动完成相位对齐补偿，将零点不确定度压制到了微米级别。
