# 传感器基础

传感器是一种能感受规定的被测量，并按照一定的规律转换成可用信号的装置。

## 基本概念

- **被测量**：传感器要测量的物理量（如温度、压力、光强等）
- **输入量**：作用在传感器上的被测量
- **输出量**：从传感器输出的信号（通常是电信号）
- **转换函数**：输入量与输出量之间的关系，记为：$Y = f(X)$

## 传感器的分类

### 按物理原理分类

1. **电阻式传感器**：利用被测量对材料电阻率的影响
2. **电容式传感器**：利用电容值随被测量的变化
3. **电感式传感器**：利用线圈电感的变化
4. **光学传感器**：利用光电效应和光学原理
5. **热电式传感器**：利用热电效应（如 Seebeck 效应）

### 按工作方式分类

- **有源传感器**：输出信号无需外接电源
- **无源传感器**：需要外接电源供电

## 性能指标

| 指标 | 符号 | 定义 |
|---|---|---|
| 灵敏度 | $S$ | 输出变化量与输入变化量的比值 |
| 精度 | - | 测量结果与真实值的符合程度 |
| 线性度 | $\gamma$ | 实际特性曲线与理想直线的偏离程度 |
| 滞后 | - | 升程和降程特性曲线不重合的现象 |
| 频率响应 | - | 传感器对不同频率输入的响应能力 |
